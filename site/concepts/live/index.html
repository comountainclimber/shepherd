A little more direction

Give the work a path.

Long tasks are easier to trust when you can see the shape of them. Shepherd keeps the plan, progress, and proof together as your agents work.

01 / OUTLINE

Plan it.

Break a task into steps, set what Done when means, and see the whole outline before work starts.

02 / MAP

Run it.

Watch steps move across the map. Run independent work side by side, with a place for your own steps too.

03 / CHECKS

Check it.

Follow the timeline and check the work against the step. When something drifts, send it back with feedback.

04 / HANDOFF

Merge it.

Keep work in its own branch and folder, then bring it together with a merge request step.

The actual app

A clear view, even when the work gets messy.

From the map to the details, the context stays with the task—not buried in a chat.

Local by nature.
Open by design.

Shepherd uses your own agent logins, repositories, connectors, and skills. There’s no Shepherd server, and nothing goes to one.
