# Watch it work

The page opens with a small, animated task map: a step starts, a check catches drift, and feedback sends the work back. The rest of the page follows the same path—plan, run, check, merge—and grounds the illustration in screenshots of the actual app.

It is aimed at developers who already use coding agents and need a clear sense of where a long task stands. The install command is available immediately and again after the local-first explanation.

From another direction, I would borrow a deeper interactive walkthrough of an actual task, if it can retain the speed and clarity of this small overview.
